# 🖼️ `assets/` — Recursos Visuales, Diagramas y Mockups

Directorio para centralizar las imágenes, diagramas exportados y diapositivas del proyecto **R.E.D. ATLAS**:

* **`assets/diagrams/`:** Diagramas de arquitectura, flujos de datos y mapas conceptuales exportados (PNG/SVG) por **Persona 1** y **Persona 3**.
* **`assets/mockups/`:** Capturas, wireframes visuales de la Consola 3D (*Spyglass* de 3 sectores) y del HUD AR del casco generados por **Persona 2**.
* **`assets/pitch/`:** Presentación final (PDF/PPTX), logos del equipo **Red Project** y recursos del vídeo para NASA Space Apps.
