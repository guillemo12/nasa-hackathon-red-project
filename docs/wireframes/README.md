# Wireframes

Wireframes de concepto de las pantallas de la consola, anteriores a la implementación:

| Fichero | Pantalla |
| :--- | :--- |
| `3d-console.png` | Cartografía y gemelo 3D con la lupa Spyglass |
| `route-planificator.png` | Planificador de ruta y simulación Chaos Mode |
| `eva-hud-nominal.png` | Telemetría EVA en estado nominal |
| `eva-emergency.png` | Telemetría EVA en multiemergencia |

> **Aviso:** las cifras que aparecen en estas imágenes son de maqueta y están **superadas**. Ejemplos: 99,4 %, 0,6 %, 64 min, 8 min, 680 m, 4,88 km y dosis «letales». La consola implementada ([`src/base-console/`](../../src/base-console/)) y la documentación usan las cifras calculadas por el motor:
>
> - refugio WP3 en 9,4 min (595 m);
> - retorno a la Base en 48 min sobre 2,15 km;
> - Chaos Mode con 96,0 % de misión segura con refugio frente a 23,8 % solo con la Base;
> - replanificación en 17 ms.
>
> La fuente es [`DATOS_CANONICOS.md`](../01-planetary-science-mission/DATOS_CANONICOS.md).
