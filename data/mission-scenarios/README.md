# 📍 `data/mission-scenarios/` — Escenario "Triángulo de Supervivencia" (Melas Chasma)

Espacio para almacenar la definición de los 4 nodos de la misión **EVA-07 en Valles Marineris (Melas Chasma)**:
* **Nodo 0 (Base / Hábitat):** Terraza aluvial estable.
* **Waypoint 1 (ISRU / Agua):** Depósito estratificado de sulfatos polihidratados.
* **Waypoint 2 (Geología / Peligro):** Lóbulo de deslizamiento y falla con pendiente $>20^\circ$.
* **Waypoint 3 (Refugio de Emergencia):** Oquedad bajo escarpe vertical con blindaje contra radiación SPE y tormentas.
