# 🖥️ `src/base-console/` — Consola Estratégica 3D de Base (Hábitat)

Módulo correspondiente al **Nodo 1 (Base Edge Server)** diseñado por la **Persona 2 (UX/UI)** y la **Persona 3 (Arquitectura)**:
* Renderizado 3D del cañón de **Valles Marineris — Melas Chasma** (Cesium / 3D Tiles).
* Componente interactivo **Lupa Espacial (*"Spyglass"*) Dividida en 3 Sectores** (*CRISM Agua + THEMIS Inercia Térmica + MOLA Pendiente*).
* Panel de **Simulación *"Chaos Mode"*** (Prueba de estrés estocástica Pre-EVA).
* Sincronizador de paquetes de malla hexagonal ligera hacia el traje EVA.
